# How To Block

> Step-by-step instructions with optional HowTo structured data for search engines.

---

## Overview

The How To block presents a numbered list of steps — a recipe, setup guide, or any sequential process. Optional schema markup describes the guide to search engines.

---

## Fields

| Field | Description |
|-------|-------------|
| **Title** | Heading for the guide |
| **Description** | Optional overview |
| **Total time** | Optional duration (for example `PT30M`) |
| **Estimated cost** | Optional cost and currency |
| **Steps** | Repeatable steps (name, instructions, optional image and URL) |
| **HowTo schema** | Add schema.org HowTo markup for SEO |
| **Alignment / background / padding** | Section chrome shared with other blocks |
